# The module covers both the loading and persistence of hive data.

The document LuaNodeAPI.md covers the Lua bindings available to a hive's `coreScript`/`pokeScript` sources, on a per concrete node type basis.

The document /json/hiveSchema.json is a JSON schema that can be used to define a hive which can be loaded into a hive collection running in an instance of Matrytsya.
